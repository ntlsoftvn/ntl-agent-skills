Bạn dùng app nào?Which app do you use?

1

Mở Customize → PluginsOpen Customize → Plugins

Bấm biểu tượng Customize ở thanh trái, rồi chọn Plugins.

Click the Customize icon in the left rail, then Plugins.

2

Bấm Add → Add a marketplaceClick Add → Add a marketplace

Nút Add ở góc phải mở một menu; chọn Add a marketplace.

The Add button in the corner opens a menu; pick Add a marketplace.

3

Dán link, bấm Add marketplacePaste the link, click Add marketplace

Dán link ở đầu trang vào ô Source, để nguyên các ô còn lại, bấm Add marketplace. Marketplace hiện tên NTL.

Paste the link from the top of this page into Source, leave the other fields as they are and click Add marketplace. The marketplace shows up as NTL.

4

Tìm plugin NTLFind the NTL plugin

Trên trang Plugins, chọn tab Personal. Marketplace NTL hiện ra với plugin NTL; bấm vào để mở.

On the Plugins page, pick the Personal tab. The NTL marketplace appears with the NTL plugin; click it to open.

5

Cài plugin NTLInstall the NTL plugin

Bấm Install. Cài xong nó nằm trong mục Installed với hai skill Proposal và Training đang bật.

Click Install. Once installed it sits under Installed with the Proposal and Training skills switched on.

1

Mở Customize → PluginsOpen Customize → Plugins

Ở thanh bên bấm Customize, rồi chọn tab Plugins ở đầu trang.

In the sidebar click Customize, then the Plugins tab at the top.

2

Bấm Add → Add marketplaceClick Add → Add marketplace

Nút + Add ở góc phải mở một menu; chọn Add marketplace.

The + Add button in the corner opens a menu; pick Add marketplace.

3

Dán link, bấm SyncPaste the link, click Sync

Dán link ở đầu trang vào ô URL, chọn gợi ý rồi bấm Sync. Marketplace hiện tên ntl.

Paste the link from the top of this page into URL, accept the suggestion and click Sync. The marketplace shows up as ntl.

4

Tìm plugin ntlFind the ntl plugin

Vẫn trong tab Plugins, chọn Yours. Plugin Ntl nằm ở mục From marketplaces you added; bấm vào để mở.

Still on the Plugins tab, pick Yours. The Ntl plugin is listed under From marketplaces you added; click it to open.

5

Cài plugin ntlInstall the ntl plugin

Bấm Install. Cài xong công tắc bật xanh và tab Skills hiện /proposal, /training.

Click Install. Once installed the switch turns on and the Skills tab lists /proposal and /training.
